## P1｜必須人工確認

### P1-01｜正式生日／1999 時間線衝突

第 155 章將樓慕妍描述為「四歲」的研究對象，並把研究往事連到約二十七年前；第 178 章又以 1999 年、五歲的樓慕妍回憶重建 Project Rose。

目前系列 Canon 已固定樓慕妍生日為 **1998-10-30**。因此以 2026 年現在時間計算，1999 年不可能是她五歲，也不可能是她四歲。

**結論：P1 時間線衝突。**

不得自動改成其他年份，必須由作者決定：
- 保留 1999 並調整年齡／出生設定；或
- 保留 1998-10-30 Canon 並重新校準研究事件年份；或
- 若 1999 是研究資料中的偽造／標記日期，需在正文建立明確證據。

證據：第 155 章研究回憶寫「四歲」；第 178 章明示時間 1999 年並出現五歲樓慕妍。

### P1-02｜樓承玦／樓承謙父親身分不一致

121–170 章的父系線多次使用「樓承玦」作為樓慕妍父親；但第 175、178 章改為「樓承謙」並明確稱其為父親。

這不是一般錯字可安全修正，因為兩個姓名可能代表不同人物，也可能是同一人物的版本殘留。

**結論：P1 身分衝突，禁止自動合併。**

需人工確認：
- 樓承玦與樓承謙是否同一人；
- 若同一人，哪一個才是正式 Canon 姓名；
- 若不同人，兩人的父系／研究／保護角色如何區分。

### P1-03｜樓慕妍母親身分出現兩套姓名

第 123–124 章出現「樓清妍」並明確由她說「我是妳母親」；後續章節又由「沈蘭心」以母親身分與樓慕妍互動，並多次使用「媽媽」稱呼。

目前文本沒有足夠明確的身分轉換規則來證明兩人是：
- 同一人的不同身分／別名；
- 生母與養母；
- 不同時間線人物；或
- 純姓名殘留。

**結論：P1 人物身分衝突，禁止自動改名。**

### P1-04｜白景深／白景言 K-01/K-02 身分線需要與早期版本重新對齊

第 165–169 章建立的新設定是：白景深＝K-01、白景言＝K-02，且 K-02 曾被宣告死亡後由蘇婉寧帶走。

這條線本身可以形成完整伏筆回收，但前面章節曾出現「000／003／J-0000」等另一套白景深複製／身份分裂邏輯。

**結論：需進行跨 1–120 章的身份 Canon 對照，確認 K-01/K-02 是否與 000/003/J-0000 同一套世界觀規則。**

### P1-05｜J-00 的「人／代號／理念」三種定義衝突

第 177 章：`J-00｜Jennifer`、`Age：29`、`Status：Primary Subject`、`Project Founder：Confirmed`。

第 178 章卻明確說：
- J-00 不是一個人；
- J-00 是 Jennifer 建立的理念；
- J-00 可以由下一代主動接受。

後文又讓 Jennifer 以真人身分出現並直接承接 J-00。

這可能是有意設計的「代號 → 理念 → 傳承」三層結構，但目前沒有明確規則文字把三者固定區分。

**結論：P1 世界觀／代號定義待人工確認。**

## P1-06｜第 150 章與第 180 章出現重複懷孕事件

第 150 章已明確建立：
- 樓慕妍已懷孕；
- 約六週；
- 白景深確認即將成為父親；
- `PROJECT ROSE II` 因懷孕資料正式啟動。

但第 180 章又寫：
- Project Rose 結束後「幾個月後」；
- 樓慕妍再次出現「我們好像要當爸爸媽媽了」；
- 並再次揭示懷孕。

這不是單純伏筆，而是同一作品正文中的明顯事件重複。

**結論：P1 劇情時間線／版本殘留。**

需要作者決定：
1. 第 180 章是否原本是另一個舊版結局；
2. 白玫懷孕應保留第 150 章並刪除第 180 章重複揭示；或
3. 第 180 章才是正式懷孕時間點，則第 150–179 章的孕期內容需整體重新定位。

**禁止自動修正。**

## P1-07｜Project Rose／Project Rose II／Phase III 的階段關係需固定

正文先後出現：
- Project Rose
- PROJECT ROSE II
- Phase III
- Original Archive J-00
- ORIGIN
- Eden

第 150 章已啟動 Project Rose II；第 176 章又宣告 Project Rose terminated；第 177–178 章仍出現 Project Rose Original Archive／J-00。

若設定為「主計畫終止但原始檔案仍存在」，邏輯可以成立，但需要在 Bible 中明確定義：
`Project Rose`、`Project Rose II`、`Phase III`、`Original Archive` 是否為同一計畫的不同階段，或不同計畫。

**結論：P1 世界觀／研究代號待人工確認。**

## P1-08｜白景珩、樓承謙、樓承玦、顧沉舟、Jennifer 的「真正創始者／投資者／執行者」關係需要統一

後段逐步揭露：
- Jennifer／J-00 是最早核心；
- 白家是早期投資者；
- 顧沉舟是後期核心研究者／執行者；

**結論：需要建立「研究史時間軸＋人物職能矩陣」後才能判定是否是真伏筆。**

第 178 章明確寫：Jennifer 選擇樓慕妍進 Project Rose，並建立 E-01。

**結論：P1 定義衝突，待人工確認。**
