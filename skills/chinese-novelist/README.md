本目錄整理並吸收開源專案 `PenglongHuang/chinese-novelist-skill` v2.0 的核心方法，並依 Jemora／知遙小說工作室的實際出版流程重新整理。

## 核心能力
1. 初始化：讀取既有作品設定、人物、時間線與未完成狀態。
2. 需求理解：題材、主角、核心衝突、世界觀、敘事視角、主題、讀者定位與篇幅。
3. 故事規劃：故事核心、世界觀、人物弧線、人物關係、主線、副線、伏筆、反轉與章節結構。
4. 章節創作：每章依前後章因果推進，重視衝突、場景、心理、對話潛台詞與章尾鉤子。
5. 連續創作：進入正式寫作後不逐章等待使用者說「繼續」，依既定規格完成全稿。
6. 校驗修訂：檢查人物一致性、時間線、關係、伏筆、世界觀、字數與文字邏輯；修改後重新整合全書。
7. 出版輸出：完稿後依 Jemora 規格製作 DOCX、TXT、PDF、Kobo EPUB 與出版 metadata。
8. 影像延伸：保留章節／場景結構，供小說→影集、字幕、有聲劇與音樂流程使用。

## Jemora 固定優先規則
- 使用者最新設定優先於舊設定。
- 預設繁體中文。
- 作者筆名：知遙。
- 作品必須維持人物、時間線、關係、伏筆及世界觀一致。
- 不用摘要或幾百字簡化內容冒充正式小說正文。
- 每章完成後回報該章中文字數。
- 使用者說「開始寫」時，直接依專案設定完成全書初稿，不採逐章等待。

## 參考原專案的三條核心法則
- 展示而非講述：用動作、場景與對話呈現。
- 衝突驅動劇情：每章至少有推進、衝突、發現或轉折。
- 懸念承上啟下：章尾留下自然的下一步動力。

## 重要差異
原專案偏向 10–50 章、每章約 3000–5000 字的網文流程；Jemora 的長篇小說可依各作品既定規格調整，例如《四姊妹》系列固定 180/200 章，因此不直接套用原專案的章數上限。
