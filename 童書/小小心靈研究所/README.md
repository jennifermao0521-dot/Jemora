# 小小心靈研究所｜給孩子的心理學小故事

作者：知遙

## 系列規格

- 共 10 冊
- 每冊固定 40 頁
- 成品尺寸：8 × 10 英吋
- 圖片比例：4:5 直式
- 圖片為主、文字為輔
- 每冊同時製作中文版與英文版
- 每冊均保留獨立中文圖片資產與英文圖片資產
- 角色、畫風、色調、版型需跨冊維持一致

## 10 冊正式設定

| 冊次 | 中文書名 | 主題 |
|---|---|---|
| 01 | 《今天，我的心裡下雨了》 | 認識難過 |
| 02 | 《小熊為什麼一直擔心？》 | 認識擔心與焦慮 |
| 03 | 《生氣的火山》 | 認識憤怒 |
| 04 | 《一個人的午餐》 | 孤單與同儕關係 |
| 05 | 《我不想去學校》 | 學校適應 |
| 06 | 《腦袋裡的小聲音》 | 理解想法與情緒 |
| 07 | 《今晚，我睡不著》 | 睡眠與情緒 |
| 08 | 《那一天，小狗不見了》 | 失落與哀傷 |
| 09 | 《爸爸媽媽吵架的晚上》 | 孩子面對家庭衝突 |
| 10 | 《如果心裡一直很累》 | 何時需要尋求專業協助 |

## 圖片上傳規則

- 中文版圖片放入各冊 `中文版/圖片/`
- 英文版圖片放入各冊 `English/Images/`
- 固定 4:5 直式比例
- 固定出版尺寸 8 × 10 英吋
- 圖片以故事敘事為主，文字為輔
- 中英文版本保持同一故事內容、角色設定、構圖邏輯與視覺風格
- 圖片檔案依頁碼順序管理，後續製作出版檔時保持頁面一致

## 系列核心

本系列以兒童日常生活中容易遇到的心理與情緒經驗為核心，讓孩子透過故事與圖像認識自己的感受、理解情緒與想法，並知道在需要時可以向可信任的大人或專業人士求助。

正式書名與主題已全部確定，後續製作以本 README 為系列設定基準。
