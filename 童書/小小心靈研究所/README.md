## 系列規格

- 共 10 冊
- 每冊固定 40 頁
- 成品尺寸：8 × 10 英吋
- 圖片比例：4:5 直式
- 圖片為主、文字為輔
- 每冊同時製作中文版與英文版
- 每冊均保留獨立中文圖片資產與英文圖片資產
- 角色、畫風、色調、版型需跨冊維持一致
